# LUCIANO_FRANCHINO_TASK

Small demo of a 2D adventure game. 
Prioritizing good practices, clean and scalable code. 


Mechanics
Inventory system: Where you can collect, use, move and delete objects from it. In turn, each one has a description.
Crafting system: With some objects you have in your inventory you can create new objects.
Mission System (WIP): Some NPCs will give you small objectives to complete, each with rewards.
Combat: At the moment we have only one ranged weapon to eliminate enemies.
Collection of resources: We have tools such as pickaxes and axes to collect materials for the creation of other objects.
